# tools

Workspace tooling, such as `tools/architecture-checks`, `tools/fhir-element-table`, `tools/codegen` (the Bun generators of `@health/fhir-types` and `@health/api-client`) and `tools/synthetic-data` (synthetic Ugandan patients and facility data, loaded through the FHIR API). Created lazily, when the first task needs them ([crate-catalogue.md](../docs/architecture/crate-catalogue.md)).
