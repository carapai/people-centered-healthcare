# @health/api-client

Zod schemas and types for each runtime's HTTP API, generated by `tools/codegen` from its `utoipa` OpenAPI document (client-application.md § Types; ADR 0036).

- **`openapi/central.json`** is central's document (`cargo run -p central-server -- openapi`), committed so that API changes show up in review.
- **`src/central.ts`** is generated: do not edit it. It holds a Zod schema and a type per DTO, and `operations`, which gives each operation's method, path and response schemas by status.
- **`parseResponse(operation, status, body)`** validates a body parsed with lossless-json. It throws a `ResponseError` for an undocumented status or a mismatched body, carrying Zod's issue paths and codes, never the values. Transports call it at the boundary.
- **`integer` and `decimal`:** a JSON integer becomes a JS number (rejected beyond the safe range), and any other number stays a `LosslessNumber`.

```sh
bun run check   # typecheck, lint, tests
```
